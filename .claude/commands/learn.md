# /learn

Teach the user a topic using the existing wiki.

Steps:

1. Search `index.md`.
2. Find relevant wiki pages.
3. Read those pages.
4. Determine what the user already knows.
5. Explain the topic from that starting point.
6. Give examples or exercises when useful.

Do not modify the wiki automatically.

If the conversation produces valuable knowledge,
suggest saving it with `/ingest` or another explicit save operation.
