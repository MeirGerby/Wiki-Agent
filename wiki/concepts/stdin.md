# Standard Input (stdin)

## Definition
The default stream where a program reads its input data, typically mapped to the keyboard or a pipe output.

## Mental Model
Think of it as the mouth of a program, swallowing incoming text data from an upstream source.

## Example
```bash
cat | grep "error"
```
