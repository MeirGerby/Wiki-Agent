# Standard Output (stdout)

## Definition
The default stream where a program writes its output data, typically mapped to the terminal text interface.

## Mental Model
Think of it as the megaphone of a program, broadcasting the final results downstream.

## Example
```bash
echo "success" > log.txt
```
