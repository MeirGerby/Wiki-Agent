# Linux Cyber Learning Path

## Definition
A 20-step path from Linux basics to security investigation and a lab-based security assessment, in four stages: A foundations, B networking, C Linux security, D tools and practice.

## Mental Model
Each stage builds the next: Linux and networking (steps 1-10) are the base for everything later, so do not skip them. All testing happens on systems you own or have explicit permission to test.

## Example
Daily routine from the source: 45-60 minutes, split into 10 min concept, 25 min commands and practice, 10 min Markdown summary, 5 min review questions without notes.

Stages: A [[linux-permissions]], [[linux-processes-services]]; B [[network-fundamentals]], [[packet-capture]], [[network-scanning]]; C [[log-investigation]], [[linux-firewall]], [[system-hardening]], [[persistence-mechanisms]], [[suid-and-capabilities]]; D [[cyber-lab]], [[web-security]], [[incident-response]], [[security-assessment-report]].

Note: the Hebrew outline is the original; the stage files expand it with general-knowledge commands and explanations.
