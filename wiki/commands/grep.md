# grep

## Definition
Global Regular Expression Print. A command-line utility used to search text files or streams for lines matching a specific pattern.

## Mental Model
A smart sifter or filter screen. You pour raw text through it, and only the pieces matching your geometric shape drop through to the bottom.

## Example
```bash
grep -r "error" ./logs
```
