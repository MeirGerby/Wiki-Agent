# English Learning

Source material for learning English, built from the 20-step guide supplied by the user.

- `english-learning-path-20-steps.md` — the guide, translated to English
- `steps/step-01..20-*.md` — one guided lesson file per step (goal, learn, exercise, common mistakes for Hebrew speakers, summary prompts, review questions)

Stages: A foundations (1-5), B understanding (6-10), C active learning (11-15), D intermediate+ (16-20).
