# Step 4 — Check

Goal: confirm understanding and remember it for next time.

1. Use the result of step 3 and ask 1-3 questions that need the learner to apply the idea, not repeat it (predict an output, spot a bug, explain why).
2. Judge the answers. Name what is right, then correct what is wrong with a pointer to the wiki page.
3. Update `learn/profile.md`: move concepts to *Known* or *Gaps*, add notes on what helped, and set the date.
4. Suggest 2-3 next topics from the Related Concepts links.
5. If the session produced new knowledge, offer `/ingest`. Do not edit the wiki.

Output: feedback, the profile changes you made, next-topic suggestions.
