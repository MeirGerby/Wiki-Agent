# Step 0 — Review

Goal: keep earlier learning from fading before adding new material.

1. Read `learn/profile.md`. Skip this step if *Known* is empty.
2. Pick 1-2 concepts in *Known* that have not been reviewed the longest (oldest date in the profile).
3. Ask one short application question for each, without hints.
4. If the answer is solid, keep the concept in *Known* and refresh its date. If shaky, move it to *Gaps* and re-teach it briefly in step 2.
5. Keep it under two minutes. This is a warm-up, not a quiz.

Output: which concepts were reviewed and the result. Profile changes are written in step 4.
