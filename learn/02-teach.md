# Step 2 — Teach

Goal: explain the topic from the learner's level, using the wiki.

1. Start from a concept they already know (from step 1) and build one step at a time.
2. Lead with a concrete example from the wiki page before the definition.
3. Use the page's Mental Model for the intuition. Use the learner's own words and domain where possible.
4. Teach missing prerequisites first, briefly, then the target concept.
5. Pull in Related Concepts only when they help. Do not repeat what the learner already knows.
6. Label wiki content versus general knowledge. Flag contradictions or gaps in the wiki.
7. Keep each explanation short. Stop after one idea chunk and let the learner react.

Output: the explanation, with `[[links]]` to the pages used.
